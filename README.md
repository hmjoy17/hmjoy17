# Lipik

**Private, offline-first tools for Bangla typing.**

## Lipik Keyboard

A privacy-first Android keyboard built for Bangla.

- **Offline by design** — typing works without internet; what you type never leaves your device
- **No ads, no tracking** — no analytics, no accounts, no data collection
- **ফোনেটিক typing** — write Bangla in English letters, powered by an 82,000+ word dictionary
- **Six languages** — Bangla, English, Hindi, Nepali, Urdu and Arabic language packs
- **Your data, your control** — your personal dictionary stays on your phone

Dictionaries & language packs: [lipik-dict](https://github.com/hmjoy17/lipik-dict)
